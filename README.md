# DVL System PWA

GitHub Pages 업로드용 파일입니다.

업로드할 파일:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

GitHub Pages 설정:
1. 새 Public 저장소를 만듭니다.
2. 위 파일 5개를 저장소 최상위에 업로드합니다.
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / (root)
6. Save

사이트 주소:
https://사용자이름.github.io/저장소이름/

아이폰·아이패드:
Safari에서 사이트 열기 → 공유 → 홈 화면에 추가 → 웹 앱으로 열기
